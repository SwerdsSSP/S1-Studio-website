# S1 Studio

Сайт команды с общей лентой проектов. Ссылки, описания и версии сохраняются сервером в `data/projects.json`, поэтому публикации доступны всем посетителям этого экземпляра сайта.

## Запуск на компьютере

Нужен Node.js 20 или новее. В папке проекта задайте пароль администрирования и запустите:

```powershell
$env:ADMIN_PASSWORD='ваш пароль'
$env:SESSION_SECRET='длинная случайная строка для подписи сессий'
npm start
```

Откройте `http://localhost:3000`. Пароль не хранится в файлах сайта: он задаётся только в окружении сервера. После входа браузер запоминает режим разработчика на этом IP до одного года; при смене IP потребуется войти заново. Форма приложения принимает файл до 100 МБ, а карточки с приложениями дают ссылку на скачивание. Режим разработчика показывает кнопки публикации и удаления. Перед удалением показывается подтверждение; для приложения удаляется и прикреплённый файл.

## Размещение в интернете

Проект подготовлен для Render через `render.yaml`: Web Service на Node.js, постоянный диск 1 ГБ и сохранение публикаций в `/var/data`. При создании сервиса в Render укажите `ADMIN_PASSWORD`; `SESSION_SECRET` генерируется автоматически. Не переносите пароль в исходный код.

На Render постоянный диск доступен платным Web Service и тарифицируется отдельно ($0.25 за ГБ в месяц); сам сервис Starter стоит $7 в месяц по текущей таблице Render. Итого минимум около $7.25 в месяц без учёта регистрации домена. Бесплатный сервис не сохраняет локальные файлы между перезапусками, поэтому для каталога работ он не подходит.

Для приложения файл прикрепляется прямо в панели публикации. Максимальный размер файла — 100 МБ.
